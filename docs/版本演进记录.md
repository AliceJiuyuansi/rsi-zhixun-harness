## v1 · 建立续训基线

**平台与实现**　镜像 0.1，初始实现 `97df9b5`。2026-11-21 完成试运行。

**方案与思路**　先验证平台能否连续十轮读取阶段数据、从父检查点续训、比较候选并交付可用模型。同时记录分类、回归和训练开销，作为后续改动的比较起点。

**实现手段**　通过平台 SDK 接入 A 分类与 B/C 剩余寿命回归。每轮按预算训练候选，在公开验证集评估后决定采用候选或保留父模型。

**实测与取舍**　A/B/C 各完成 10 轮。A macro-F1 为 0.8735；B MAE 为 506.67 分钟；C MAE 为 41.12 循环，NASA 为 8.85×10¹⁰。三题 CPU 时间分别为 993、368、1868 秒。A 连续采纳候选，B 从第 3 轮、C 从第 4 轮起持续拒绝候选却仍付出训练成本。因此下一版优先压缩无收益的续训，保留 A 的更新机会。[平台运行明细](../reports/trial_runs.md)

## v2 · 用跨轮证据分配训练预算

**平台与实现**　镜像 0.2，提交 `048bd98`。平台版本 `8636a3d…`，2026-11-23 完成试运行（run `2b638d5a…`）。

| 观察与改进思路 | 实现手段 | 验证时看什么 |
|---|---|---|
| 只看当前轮难以区分阶段变化与持续停滞 | 回读历史指标、特征与预测分布，计算跨轮漂移，使用连续未改善次数选择预算 | 阶段切换时的漂移值、规则和预算是否对应 |
| B/C 多次重训后仍沿用父模型 | A/B/C 单轮预算上限设为 5/4/3 个 epoch，加入停手与探针试训 | 拒绝连续发生后是否出现零训练轮，指标是否保持 |
| 回归最优值初始为 0，模型回复也可能被漏读 | 修正回归初值，兼容 reasoning_content，缺少模型文本时记录 unavailable | 首轮基准值是否有效，后续裁决是否能追溯 |
| 模型建议需要约束，候选收益需要可比较 | 将动作白名单、幅度、预算、停机开关和审计接入执行流程，在同一验证集比较父子模型 | 被拒的动作、候选和最终采用的检查点是否有记录 |

**验证与取舍**　基于 v1 历史信号的反事实回放，A/B/C 分别从 28/50/41 个 epoch 变为 28/17/18，估算节省 1291 CPU 秒。回放沿用旧候选分数，无法据此推断改变训练轨迹后的精度。

**实测（2026-11-23，run `2b638d5a…`）**　A/B/C 各完成 10 轮。相对 v1：A macro-F1 0.8735→0.8674（-0.69%）；B MAE 506.67→**251.70**、RMSE 708.58→**352.08**（约 -50%）；C 仍选第 3 轮模型，指标逐位不变。总 epoch 119→**66**（-44.5%），墙钟 8,160→**3,917 s**（-52%），CPU 3,229→3,044 s（-5.7%），token 22,366→32,087。停手规则在 B 第 4/6/7 轮、C 第 5/6/8/10 轮生效（7/30 轮）。结论：B 的收益来自“校准 3 epoch + 第 8/9 轮再训”，不是单纯少训；A 需把新阶段预算调回 3；C 的问题在预测上限，留给 v3。[平台运行明细](../reports/trial_runs.md)

## v3 · 收紧候选验收，限制 C 的极端预测

**平台与实现**　镜像 0.3，提交 `1702008`，平台版本 ID 为 `b318577fbc02cdfeb8504ac94c707c10`。11 月 23 日浏览器核对时校验通过。沿用 v2 控制器和训练预算。

| 观察与改进思路 | 相对 v2 的实现变化 | 待验证的收益与代价 |
|---|---|---|
| C 的 NASA 对极端误差敏感，过高预测可能主导总分 | 在预测出口将 24 特征 C 任务的剩余寿命限制在 0–145 个循环 | 对照 v1 同看 NASA、MAE 和 RMSE，检查限制高估是否引入低估；145 是本版策略参数 |
| 验收容差允许轻微退步，与保留较优父模型的目标冲突 | 分类和回归的退步容差降至浮点误差范围。晋升仍要求 macro-F1 至少增加 0.002，或 RMSE 相对下降至少 0.2% | 检查逐轮 gain、retain、promote，区分真正无增益和阈值拦截 |

**平台实测（2026-11-23）**　[试运行报告](https://rsi-index.115.zone/#runs)，run `27143ad15abd6f1a4daf998200625545`。三题各 10/10 轮，记录完整，共预测 14,773 条。A 最终选第 10 轮，accuracy 0.872902、macro-F1 0.867426；B 选第 9 轮，MAE 251.697725 分钟、RMSE 352.082921 分钟。两题均与 v2 持平（按平台展示精度）。C 仍选第 3 轮，MAE 41.120720 → 43.787114，RMSE 56.381900 → 62.881078，NASA 8.8527×10¹⁰ → 2.4400×10¹²（升至 27.56 倍，越低越好）。CPU 合计 3,075.16 秒，三题运行用时合计 3,729.87 秒，31,985 tokens。

**原因核查**　v3 收紧候选验收容差，晋升阈值未变。两版逐题的晋升轮次一致，门槛变化未带来新的模型选择。另一项变化在 24 特征回归的预测出口，训练端评估仍直接使用模型原始输出。官方 C 题说明定义公开完整轨迹的标签为 T−t，回归目标不封顶。将特定测试协议的末循环寿命范围推广为所有样本的上限，缺少依据。

**公开验证对照**　固定官方 C 起始 checkpoint，对 public/validation.jsonl 的 23,049 条样本只切换 145 上限。7,599 条真值超过 145（最大 434），7,736 条预测受到截断。MAE 38.90 → 41.19，RMSE 52.87 → 58.72，按逐样本 NASA 公式求和为 5.82×10⁹ → 7.37×10¹⁰。截断压低了高估惩罚，同时放大了长寿命样本的低估惩罚，后者主导总分。此对照使用公开起始模型；隐藏集逐样本误差归因仍不可见。

**取舍**　保留已验证的 B 预算策略。C 以 v2 无上限结果为基线，撤回 145 硬上限；后续输出变换先在同一 checkpoint 和公开验证集上经过实际预测路径比较 MAE、RMSE、NASA，再决定是否使用平台额度。

## 后续版本模板

复制本节到模板之前。每个实际创建的平台版本单独记录，即使只改文档或最终没有试运行，也注明差异和状态。

- **版本与状态**　平台版本号、日期、来源版本、镜像标签、代码提交、校验或运行状态。
- **方案与依据**　上一版哪一轮、哪项指标或哪条日志暴露了什么问题？本版目标是什么？
- **改进手段与思路**　逐项记录修改位置、行为变化、选择该做法的理由、预期收益与代价。
- **验证与结果**　写明比较对象、数据来源、本地测试或回放结果。平台运行后补 run ID、三题指标、成本与异常；尚未测量的项目写「待验证」。
- **取舍与下一步**　依据哪些结果保留、回退或继续调整？多项改动一同上线时，注明仍无法单独归因的部分。
