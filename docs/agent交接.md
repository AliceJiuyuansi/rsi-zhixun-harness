## 两版为什么遇到困难

**v9 选模主要看 RMSE。** C 先做工况残差校准（±10 个循环），再叠加残差树（合计 ±15）。相较 v5，隐藏 C RMSE 降了 0.92%，但对极端误差敏感的 NASA 升了 17.97%。第 8→9 轮选中模型的公开 NASA 从 22.10 亿升到 84.36 亿，第 10 轮沿用第 9 轮模型。各轮公开样本可能变化，要判断更新本身的影响，需要让父模型和子模型预测同一批样本。

**v11 收紧了 A 的采用条件，把 B 的逐轴承表现和 C 的 NASA 风险用于筛选每个已训练快照，再在合格者中择优。** C 原有的否决阈值是同轮 `log1p(NASA)` 增加超过 0.50，大分数下相当于允许约 65% 的升幅。在三个训练顺序的公开首轮复核中，旧选法和新选法每次都选中相同的权重，NASA 收益为零。v11 推理路径还缺少平台 v9 的 B 振动残差修正，固定同一份 B 权重时，1,679 条公开预测中有 1,665 条改变。整包替换同时动了多个因素，隐藏分退化不能归因于单个阈值。

## C 尾部的方向

在本地 v9 原顺序十轮检查点的 **23,049 条公开验证预测**中，低估贡献了总 NASA 的 **92.27%**。低估超过 200 个循环的 76 条来自 5 台发动机，贡献 **77.77%**。高估超过 200 的有 0 条。罚分最大的一条真实寿命为 361，预测为 109.07。这些比例描述公开集；平台隐藏报告只给汇总分，误差方向尚待验证。

按工况取训练真实寿命的 p99.5 作上限，六个工况共触发 **0 条**。改用训练预测的 p99.5，触发 71 条，超限部分按 0.3 倍保留后，总 NASA 仅降 0.84%。固定这批预测，即使消除所有高估罚分，单靠向下压最多也只能使总 NASA 降 7.73%。
