## 按所选版本复现

1. 使用所选版本对应源代码、官方 SDK 1.0.4 和赛方公开包。每个任务包都有起始 checkpoint 与 public/train.jsonl、public/validation.jsonl。
2. 从交付清单核对镜像 SHA-256。执行 `docker load -i zhixun-rsi-harness-0.6.tar`，然后执行 `docker run --rm --network none zhixun-rsi-harness:0.6 describe`。
3. 执行 `python -m unittest discover -s tests`。逐轮恢复父检查点时同时保留状态与候选记录；在同一阶段同一验证集比较父子。
4. 判断收益先读平台 C MAE、RMSE、NASA，再读 A/B 和 CPU、墙钟。将校准限幅、晋升轮和服务端模型回执分别记录。

## 在公开数据复核限幅

在 v6 项目根目录运行下面两条命令。将官方 SDK 放到 `_sdk/contest-harness-sdk-1.0.4`，官方 C 包放到 `data/raw/official_c`。设 `RSI_C_CALIBRATION=0`、`OPENBLAS_NUM_THREADS=1`。空回执用于复现模型裁决不可用时的规则路径。

```text
python scripts/test_harness_local.py --dataset C --rounds 3 --stage-every 10 --stub empty --save-selected out/selected.npz
python scripts/compare_prediction_caps.py C data/raw/official_c out/selected.npz out/c-limit.json
```
