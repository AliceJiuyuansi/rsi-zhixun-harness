## 2. 为什么先 v4 再 v5

- v3 的 C 145 上限被实测证伪；v4 只撤销它，A/B 不动，作为**干净对照**。
- v5 在 v4 上只加 C 校准；如果 v5 直接上，C 变好/变坏会分不清是“撤销上限”还是“校准”。
- 一次只验证一个会改变预测的假设；这是本项目已经踩过的坑（v3 只改上限，反而更差）。
