## 可直接执行的 PowerShell 命令

下面两段使用同一个 PowerShell 窗口。第一段从团队原工作区读取官方 SDK，检出固定版本到临时目录。每次导出使用新的目录以保留已有归档。Docker Desktop 需已运行 Linux 引擎。

```powershell
$ErrorActionPreference = 'Stop'
$project = 'D:\Alice_AI\rsi'
$commit = 'bb0a7f8b88c07c0eace93202de8861ecb9cf26f6'
$buildDir = Join-Path ([IO.Path]::GetTempPath()) ('rsi-v6-src-' + [guid]::NewGuid().ToString('N'))
$exportDir = Join-Path $project ('dist\v6-' + [guid]::NewGuid().ToString('N'))
$tag = 'zhixun-rsi-harness:0.6'
$sdk = Join-Path $project '_sdk\contest-harness-sdk-1.0.4'
if (!(Test-Path -LiteralPath $sdk -PathType Container)) { throw "找不到官方 SDK：$sdk" }
git -C $project fetch origin main
if ($LASTEXITCODE) { throw 'Git fetch 失败' }
git -C $project worktree add --detach $buildDir $commit
if ($LASTEXITCODE) { throw '固定源码检出失败' }
New-Item -ItemType Directory -Path (Join-Path $buildDir '_sdk') | Out-Null
Copy-Item -LiteralPath $sdk -Destination (Join-Path $buildDir '_sdk') -Recurse
New-Item -ItemType Directory -Path $exportDir -Force | Out-Null
$tar = Join-Path $exportDir 'zhixun-rsi-harness-0.6.tar'
docker build --platform linux/amd64 -f (Join-Path $buildDir 'harness.Dockerfile') --build-arg RSI_C_CALIBRATION=0 -t $tag $buildDir
if ($LASTEXITCODE) { throw 'docker build 失败' }
docker run --rm --network none $tag describe
if ($LASTEXITCODE) { throw '断网 describe 失败' }
docker save --output $tar $tag
if ($LASTEXITCODE) { throw 'docker save 失败' }
Get-Item -LiteralPath $tar | Select-Object FullName,Length
Get-FileHash -LiteralPath $tar -Algorithm SHA256
```

**使用已有 tar 时可以直接从这里开始。** 将 `$tar` 设为已有文件路径即可。第二段向团队已登录的竞赛平台上传镜像，保存本地回执并检查 `ready`。若回执只有 `pending`，先到平台归档页核对上传结果，以免导入同一份文件两次。

```powershell
$ErrorActionPreference = 'Stop'
$project = 'D:\Alice_AI\rsi'
if (!$tar) { $tar = Read-Host '输入 v6 tar 的完整路径' }
$tar = (Resolve-Path -LiteralPath $tar).Path
$file = Get-Item -LiteralPath $tar
$sha = (Get-FileHash -LiteralPath $tar -Algorithm SHA256).Hash
$receiptPath = "$tar.upload.json"
$base = 'https://rsi-index.115.zone/api/v1'
$auth = Get-Content -LiteralPath (Join-Path $project '_state\auth.json') -Encoding UTF8 -Raw | ConvertFrom-Json
$session = $auth.session.contest_session
if ($session -is [string] -and $session.StartsWith('{')) { $session = $session | ConvertFrom-Json }
$token = if ($session -is [string]) { $session } else { $session.token }
if (!$token) { throw '团队平台会话缺少 token，请登录平台后使用网页镜像上传入口。' }
$headers = @{ Authorization = "Bearer $token"; Accept = 'application/json' }
if (Test-Path -LiteralPath $receiptPath) {
    $receipt = Get-Content -LiteralPath $receiptPath -Raw | ConvertFrom-Json
    if ($receipt.sha256 -ne $sha -or !$receipt.archive_id) { throw "请核对已有上传回执：$receiptPath" }
    $archiveId = $receipt.archive_id
} else {
    @{sha256=$sha; status='pending'} | ConvertTo-Json | Set-Content -LiteralPath $receiptPath -Encoding UTF8
    $posted = Invoke-RestMethod -Method Post -Uri "$base/image-archives" -Headers $headers -InFile $tar -ContentType 'application/x-tar' -TimeoutSec 1800
    $archiveId = $posted.id
    if (!$archiveId) { $archiveId = $posted.image_archive_id }
    if (!$archiveId) { throw '已发起上传但未取得 archive ID，请核对平台镜像归档页。' }
    @{sha256=$sha; archive_id=$archiveId} | ConvertTo-Json | Set-Content -LiteralPath $receiptPath -Encoding UTF8
}
$deadline = (Get-Date).AddMinutes(20)
do {
    $items = (Invoke-RestMethod -Uri "$base/image-archives" -Headers $headers -TimeoutSec 60).items
    $image = $items | Where-Object { $_.id -eq $archiveId } | Select-Object -First 1
    if ($image.status -eq 'ready') { break }
    if ($image.status -in @('failed','error')) { throw "平台导入失败：$($image.error_code)" }
    if ((Get-Date) -ge $deadline) { throw "导入仍在进行或回执未到；再次执行本段可续查 $archiveId" }
    Start-Sleep -Seconds 10
} while ($true)
if ([long]$image.size_bytes -ne $file.Length) { throw '平台归档大小与本地文件不一致' }
$image | Select-Object id,status,size_bytes
```
