```powershell
docker build --platform linux/amd64 -f harness.Dockerfile --build-arg RSI_C_CALIBRATION=0 -t zhixun-rsi-harness:0.6 .
docker image inspect zhixun-rsi-harness:0.6 --format '{{.Os}}/{{.Architecture}}'
docker save --output .\zhixun-rsi-harness-0.6.tar zhixun-rsi-harness:0.6
Get-FileHash .\zhixun-rsi-harness-0.6.tar -Algorithm SHA256
```

新构建会生成新的归档摘要，按实际文件登记。
