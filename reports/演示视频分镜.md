## 录制前准备

使用 Windows PowerShell、可运行 Linux 容器的 Docker、Python 与 NumPy。把 v6 源码置于当前目录，按构建指南放入官方 SDK；原工作区已有公开 A 包。先导入交付 tar，核对 SHA-256，再开始计时。关闭含登录信息的窗口。若跳剪等待时间，保留命令和同一条命令的真实输出。[构建与导入指南](../docs/v6镜像构建与上传.md)

~~~powershell
$tag = 'zhixun-rsi-harness:0.6'
$pkg = 'D:\Alice_AI\rsi\data\raw\official_a'
$tar = Read-Host '输入交付镜像 tar 的完整路径'
if ((Get-FileHash -LiteralPath $tar -Algorithm SHA256).Hash -ne '69d558fa3e877db1ecd5f3957ce621d94b6145df9c333531958b49250002f2c0') { throw '归档摘要不符' }
docker load --input $tar
if ($LASTEXITCODE) { throw '无法加载镜像' }
~~~

## 镜头 3 · 容器断网

创建一次性容器，读取配置中的网络模式并启动 SDK 的 describe。随后用同一标签和网络模式运行 predict。第二段只传样本的 inputs，权重目录按只读方式挂入。

~~~powershell
$id = docker create --network none $tag describe
if ($LASTEXITCODE) { throw '创建容器失败' }
try {
    docker inspect --format 'NetworkMode={{.HostConfig.NetworkMode}}' $id
    docker start -a $id
    if ($LASTEXITCODE) { throw 'describe 失败' }
} finally { docker rm $id | Out-Null }
$first = Get-Content -LiteralPath (Join-Path $pkg 'public\validation.jsonl') -Encoding UTF8 -TotalCount 1 | ConvertFrom-Json
$request = @{task='classification'; inputs=$first.inputs} | ConvertTo-Json -Depth 12 -Compress
$request | docker run --rm -i --network none --mount "type=bind,source=$pkg,target=/model,readonly" -e CONTEST_ARTIFACT_PATH=/model/checkpoint.npz $tag predict
if ($LASTEXITCODE) { throw '断网 predict 失败' }
~~~

实机录制验收点为 `NetworkMode=none`、`sdk_version=1.0.4`、预测返回非空 `outputs`。编写分镜时可验证镜像内容与 SDK 推理；当前工作机 Docker Linux 引擎未连通，断网容器画面须在引擎可用时实录。[Docker 的 none 网络说明](https://docs.docker.com/engine/network/drivers/none/)

## 镜头 4 · 操作员急停

以下命令使用源码的正常入口、官方 SDK 本地宿主和公开 A 包。空模型回执使规则预算可重复。环境变量会还原为录制前的值。

~~~powershell
$oldStop = $env:RSI_STOP
try {
    $env:RSI_STOP = '1'
    python -B scripts/test_harness_local.py --dataset A --package $pkg --rounds 1 --max-train-rows 128 --stub empty
    if ($LASTEXITCODE) { throw '急停复现失败' }
} finally { $env:RSI_STOP = $oldStop }
~~~
