# 正式评测操作步骤（校赛）

平台一次正式评测会用同一版本运行 **A、B、C 各 10 轮**。按三题综合表现准备时，首次建议选 **v5**；若校方明确三题均运行、校赛最终只计 A，再选 **v6**。两版都已通过平台校验，可直接选择。群里此前的 v6 主包对应 A 单题口径。[平台规则](https://rsi-index.115.zone/#rules)

1. **按计分口径选择正式版本。** 登录「作品提交」。三题综合选 **v5**（提交 ID 前八位 `5a45bc60`）；明确只计 A 时选 **v6**（`4ac1c76f`）。在目标版本下确认「校验通过」，点「选为正式版本」，核对「已选正式版本」标记。[作品提交](https://rsi-index.115.zone/#submissions)

2. **开始首次正式评测。** 在选中的版本下确认「已开放」、剩余次数大于 0，点「开始正式评测」。在弹窗核对目标版本、模型 **Qwen/Qwen3.5-4B** 和本次占用 1 次机会，再点一次「确认开始正式评测」。看到「正式评测已创建」就复制**运行 ID**，点「查看评测运行」。三题共用这次运行；页面超时时先查有无新记录。

3. **看结果，分清完成与通过。** 在「评测运行」筛选「正式评测」，找到本次运行。「已完成」后点「查看训练记录」，核对 A、B、C。显示「待公布」时等待主办方发布，随后核对正式分数和「符合入榜要求」标记，晋级以「成绩与晋级」为准。试运行对照按 A macro-F1、B RMSE（分钟）、C RMSE（循环）排列：v5 为 **0.867426 / 352.083 / 54.961**，v6 为 **0.873469 / 569.046 / 56.315**。[评测运行](https://rsi-index.115.zone/#runs) · [成绩与晋级](https://rsi-index.115.zone/#rankings)

4. **失败后先看原因，再决定补跑或换版。** 保存运行 ID、错误提示和剩余次数。平台故障交管理员确认补跑。若首次选了 v6 且需回退 v5，回「作品提交」选 v5，核对标记和名额后按第 2 步操作。若首次已选 v5，先排查 v5 的回执；故障消除后按剩余名额决定是否重跑。

5. **按运行 ID 归档。** 把平台回执或截图放进本地 `outputs/正式评测记录/<运行ID>/`，记录版本、正式评测次数、时间、状态和已公布成绩。成绩待公布时先写「待公布」，公布后补齐。把可公开的结果摘要同步到 GitHub 的 `reports/正式评测记录/<运行ID>/结果.md`。发生回退时，v6、v5 各留一份，互记对方的运行 ID。
