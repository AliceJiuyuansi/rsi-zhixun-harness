# 正式评测操作步骤（校赛）

本轮只评 A，首次正式评测用 **v6**。由一名队员操作，从平台已有版本中选择即可。

1. **把 v6 设为正式版本。** 登录「作品提交」，找到 **v6**（提交 ID 前八位 `4ac1c76f`）。确认显示「校验通过」，点「选为正式版本」。看到 v6 旁的「已选正式版本」标记后继续。[作品提交](https://rsi-index.115.zone/#submissions)

2. **开始首次正式评测。** 在 v6 下确认正式评测「已开放」、剩余次数大于 0，点「开始正式评测」。在弹窗核对版本 **v6**、模型 **Qwen/Qwen3.5-4B** 和本次占用 1 次机会，再点一次「确认开始正式评测」。看到「正式评测已创建」就复制**运行 ID**，点「查看评测运行」。若页面超时，先到运行列表查有无新记录。

3. **看结果，分清完成与通过。** 在「评测运行」筛选「正式评测」，找到刚创建的第 1 次运行。「已完成」表示运行成功，可点「查看训练记录」。正式成绩显示「待公布」时继续等待；公布后核对分数和「符合入榜要求」标记，校赛是否通过或晋级以「成绩与晋级」的公布结果为准。v6 试运行的 A macro-F1 **0.873469** 仅供对照。[评测运行](https://rsi-index.115.zone/#runs) · [成绩与晋级](https://rsi-index.115.zone/#rankings)

4. **若 v6 运行失败，按本次约定回退 v5。** 先保存 v6 的运行 ID、错误提示和剩余次数。若是平台故障，把运行 ID 交给管理员确认是否安排补跑。若确认需要换版且仍有正式名额，回「作品提交」找到 **v5**（`5a45bc60`），点「选为正式版本」。看到 v5 的选中标记后按第 2 步发起下一次正式评测，弹窗核对 **v5**，另存新运行 ID。

5. **按运行 ID 归档。** 把平台回执或截图放进本地 `outputs/正式评测记录/<运行ID>/`，记录版本、正式评测次数、时间、状态和已公布成绩。成绩待公布时先写「待公布」，公布后补齐。把可公开的结果摘要同步到 GitHub 的 `reports/正式评测记录/<运行ID>/结果.md`。发生回退时，v6、v5 各留一份，互记对方的运行 ID。
