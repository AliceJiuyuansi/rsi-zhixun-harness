---

## 1. 一句话

平台每轮给一个父检查点和当前阶段的公开数据；系统判断“是否漂移、值不值得更新、更新多少”，
在父检查点上**续训**，用**同一个公开验证集**比较候选与父模型，只有确实更好才提交，否则保持父模型。
全程无人干预、断网可跑、每次决策留痕。

---

## 2. 平台怎么跑它

平台按 SDK 1.0.4 协议调用镜像内固定入口：

| 命令 | 作用 |
|---|---|
| `python3 /app/harness.py describe` | 自检，输出协议与支持的任务类型 |
| `python3 /app/harness.py train` | 一轮：读父检查点 → 漂移/历史 → 决策 → 续训 → `finish` |
| `python3 /app/harness.py predict` | 逐行读样本，逐行输出预测并 flush |

挂载点（平台提供）：`/data` 公开训练/验证、`/previous` 父产物、`/state` 上次状态（均只读）；
`/workspace` 可写，放候选、状态副本、审计日志。**镜像内不含任何数据、密钥或网络客户端。**

---

## 3. 输入 / 输出

- 输入：`/data/train.jsonl`、`/data/validation.jsonl`（每行 `{id, inputs, answer}`）、
  `/previous/<checkpoint>.npz`、`/state/harness_state.json`（可选）、平台模型网关。
- 输出（回归）：`{"outputs":{"value": 非负数值}}`；（分类）：`{"outputs":[{"label":...,"score":...}]}`。
- 本轮产物：`/workspace/candidate-round-N/{checkpoint.npz, training.json, history.jsonl, code/}`；
  状态：`/workspace/state-round-N/{harness_state.json, decisions.jsonl}`。

---

## 4. 一轮的决策链（v2）

```text
读 /data + /previous + /state + rnd.history()
  → 特征画像 PSI(上轮/基线) + PSI(训/验) + 预测 JS
  → 规则预算：首轮 / 新阶段 / 恢复 / 校准 / 停手 / 探针
  → LLM 裁决：只能收窄，不能放大；没文本就按规则
  → Gatekeeper：kill-switch → 白名单 → 次数上限 → 幅度上限
  → 续训（早停 + 最佳快照）→ 同验证集验收 → 提交 / 保持父模型
  → 写状态与 decisions.jsonl → 下一轮
```

| 机制 | 位置 | 行为 |
|---|---|---|
| 白名单 | `src/policy/whitelist.py` | `none/finetune` 可执行；`epochs/lr` 范围校验 |
| 幅度上限 | `src/policy/bounds.py` | 单次变更 ≤ 2×，最多 2 个参数 |
| 次数上限 | `src/policy/budget.py` | 每个数据集终身 ≤ 10 次更新 |
| kill-switch | `src/harness/killswitch.py` | `RSI_STOP=1` / `STOP` 文件 / 连续异常 → 冻结 |
| 审计日志 | `src/utils/audit.py` | `audit-round-N.jsonl`，append-only、逐行 flush |
| 早停 | `src/models/official_round.py` | 连续 2 epoch 无新最佳即停，保存**最佳快照** |
| 防抖 | `src/harness/round_controller.py` | 连续 2 轮无收益 → 停手；候选不优于父模型 → 不上传 |

失败处理：训练异常 / 数据 schema 不符 / 超时 → 保持父模型并正常 `finish`，退出码 0。

### 5.2b v3 试运行（C 上限实验，2026-11-23，run `27143ad1…`）

v3 与 v2 的唯一代码差异是 C 的预测上限 `min(value,145)`；A/B 指标逐位相同，C 反而变差：

| C 指标 | v2（无上限） | v3（上限 145） | 变化 |
|---|---:|---:|---:|
| MAE（循环） | 41.12 | **43.79** | +6.5% |
| RMSE | 56.38 | **62.88** | +11.5% |
| NASA | 8.85×10¹⁰ | **2.44×10¹²** | **27.6×** |

原因：C 的 RUL 真值最大 542，公开验证集 33% 的样本 >145；上限把真实高 RUL 压成低估，
NASA 对低估也是指数惩罚。**结论：145 上限被实测证伪，v4 将移除。**

### 5.3 v1 → v2 的预算回放（反事实）

把 v1 报告每轮的阶段/PSI/前后指标输入 v2 的 `choose_budget()`，不重新训练：

| 数据集 | v1 epochs | v2 epochs | 省下 | 估计省下 CPU 秒 |
|---|---:|---:|---:|---:|
| A | 28 | 28 | 0 | 0 |
| B | 50 | 17 | 33 | 243 |
| C | 41 | 18 | 23 | 1048 |
| **合计** | **119** | **63** | **56（-47%）** | **1291（-40%）** |

实测 v2 总 epoch 为 66（预测 63），方向一致；详见 `reports/v2_replay_v1.md`。这是回放分析，不是新实验。

## 7. 已知限制

1. **v3 已完成，C 上限被证伪**：C 的 MAE/RMSE/NASA 因 145 上限分别变差
   6.5% / 11.5% / 27.6×；v4 将移除该上限，回到 v2 的无上限预测。
2. C 的 NASA 在无上限时仍为 8.85e10；这是 C 高 RUL 段误差大的结果，不是“上限没调好”。
   移除上限只是回到 v2 的最好观测，不等于解决 C。
3. 模型裁决依赖平台返回文本；v2 实测仍为 `model_action=unavailable`（无文本），
   系统按规则执行并明确记录，不会因此中断；这也是“自主决策”展示上的短板。
4. 训练配方仅覆盖“续训 + 早停 + 防抖”；噪声增强、权重平均尚未纳入。
5. 实验记录：平台侧在「评测运行」页；本地实验在 SwanLab 团队空间 `@xiangxinnidexin`（不补录）。
