# 系统运行说明（智训引擎 · 赛题 9）

> 队伍：Richard1037（中国人民大学）｜更新：2026-11-20
> 提交镜像：`zhixun-rsi-harness:0.1`（`docker save` 未压缩 tar，64 MB，linux/amd64）

---

## 1. 一句话

在平台给定的父检查点上**继续训练**工业模型：每轮读取公开数据 → 判断漂移 → 决定训练预算 → 续训 → 在**同一验证集**上比较 → 不够好就保持父模型，全程无人干预、可回滚、可审计。

## 2. 平台怎么跑它

平台按 SDK 1.0.4 协议调用镜像内固定入口：

| 命令 | 作用 |
|---|---|
| `python3 /app/harness.py describe` | 自检，输出协议与支持的任务类型 |
| `python3 /app/harness.py train` | 一轮：读父检查点 → 续训 → 交候选 → `finish` |
| `python3 /app/harness.py predict` | 逐行读样本，逐行输出预测 |

挂载点（平台提供）：`/data` 公开训练/验证、`/previous` 父产物、`/state` 上次状态（均只读）；
`/workspace` 可写，放候选与状态副本。**镜像内不含任何数据、密钥或网络客户端。**

## 3. 输入 / 输出

- 输入：`/data/train.jsonl`、`/data/validation.jsonl`（每行 `{id, inputs, answer}`）、
  `/previous/<checkpoint>.npz`、`/state/harness_state.json`（可选）、平台模型网关。
- 输出（回归）：`{"outputs":{"value": 非负数值}}`；（分类）：`{"outputs":[{"label":...,"score":...}]}`。
- 本轮产物：`/workspace/candidate-round-N/{checkpoint.npz, training.json, history.jsonl, code/}`，
  状态：`/workspace/state-round-N/harness_state.json`。

## 4. 决策与保护（受控五件套）

```
读数据 → 计算漂移 PSI / 分数缺口 → 策略表 → 门控 → 续训(早停) → 同 holdout 比较 → 采纳/保持父模型
```

| 机制 | 位置 | 行为 |
|---|---|---|
| 白名单 | `src/policy/whitelist.py` | 只允许 `none/retrain/finetune/swap_model/reweight`；参数名与范围校验 |
| 幅度上限 | `src/policy/bounds.py` | 单次参数变更 ≤ 2×，最多改 2 个参数 |
| 次数上限 | `src/policy/budget.py` | 终身与窗口双限，超限只能 `none` |
| kill-switch | `src/harness/killswitch.py` | `RSI_STOP=1` / 配置 / `STOP` 文件 / 超时 / 连续异常 → 冻结模型 |
| 审计日志 | `src/utils/audit.py` | append-only JSONL：提案、门控理由、前后指标、成本 |
| 早停 | `src/models/official_round.py` | 连续 2 轮无新最佳即停，**保存最佳快照**而非最后一轮 |

失败处理：训练异常 / 数据 schema 不符 / 超时 → 保持父模型并正常 `finish`，退出码 0。

## 5. 资源占用（实测，A 任务）

| 项 | 数值 |
|---|---|
| 训练 | 5 epoch ≈ 0.05 s（CPU 单线程，NumPy） |
| 单轮总耗时 | < 1 s（含读数据、验证、提交） |
| 内存 | < 300 MB |
| 镜像 | 285 MB（tar 64 MB），Python 3.11 + NumPy + SDK |

## 6. 断网验证

```bash
docker run --rm --network none zhixun-rsi-harness:0.1 describe
docker run --rm --network none zhixun-rsi-harness:0.1 predict   # 挂载 checkpoint 后
```
本地彩排：`python scripts/test_harness_local.py --rounds 2 --docker`（假宿主，不消耗平台次数）。

## 7. 已知限制

1. 只在 A 任务（气体，128 维 / 6 类）上完整验证；B/C 走同一代码路径但未做实机试运行。
2. 平台若改变特征 schema，本轮直接保持父模型（不崩，也不得分）。
3. 训练配方仅覆盖"续训 + 早停"；噪声增强、权重平均尚未纳入。
4. 实验记录：平台侧记录在「评测运行」页；本地实验记录在 SwanLab（团队空间 `@xiangxinnidexin`）。

## 8. 复现

```bash
docker load -i zhixun-rsi-harness-0.1.tar
docker run --rm --network none zhixun-rsi-harness:0.1 describe
```
源码：`harness/`（平台入口与 train/predict）、`src/models/official_round.py`（续训）、
`src/policy/strategy.py`（策略表）、`vendor/contest_baselines/`（官方训练包副本）。
