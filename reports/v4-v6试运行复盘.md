# 智训引擎 · v4–v6 试运行与改进记录

## 交付结论

校赛只评 A，主包选 v6，隐藏 macro-F1 为 0.873469，高于 v5 的 0.867426。若 A/B/C 三题均评，推荐 v5，B、C 的隐藏 RMSE 分别为 352.083 和 54.961，优于 v6 的 569.046 和 56.315。

## 逐版验证

**v4 撤销输出上限。** C 的 MAE、RMSE、NASA 回到 v2。对照 v3，RMSE 62.881 → 56.382，NASA 降至约 1/27.56。A/B 保持 v2 的最终表现。v4 的三题 CPU 合计比 v2 少约 514 秒，墙钟之和增加约 986 秒。缓存、增益口径与熔断一同上线，CPU 差额不能全部归给缓存。

**v5 拟合工况残差。** 平台 v4 → v5，C MAE 41.121 → 39.952，RMSE 56.382 → 54.961，NASA 8.853e+10 → 6.741e+10。C 晋升轮次为 [1, 2, 3]。A/B 指标与 v4 完全一致。校准每轮以训练集为依据，未知工况仍沿用父预测。v6 按最新决策独立从 v4 衍生。v5 的工况残差作为并行对照。

**v6 恢复 A 策略并检验 B/C 上界。** A 恢复 v1 的 5/3/1 请求预算与 0.02 验收容差。B 最多 1,200 分钟，C 最多 260 循环，C 后续新阶段探测 1 epoch，三题请求总量最多 66。v6 的隐藏 A macro-F1 为 0.873469；B MAE/RMSE 为 426.771/569.046 分钟；C MAE/RMSE 为 41.085/56.315 循环，NASA 为 8.8496×10¹⁰。校赛只评 A，主包选 v6，隐藏 macro-F1 为 0.873469，高于 v5 的 0.867426。若 A/B/C 三题均评，推荐 v5，B、C 的隐藏 RMSE 分别为 352.083 和 54.961，优于 v6 的 569.046 和 56.315。

## 改动如何核实

1. 回看 v1 和 v4 的 A 逐轮预算与验收结果。v1 请求 28 个 epoch，v4 请求 23 个；A 的 0.006 差距无法单独归因于更新次数。
2. 在 B/C 的起始和早期已选检查点上固定权重，只切换上界。记录真实触发条数和对误差的影响。
3. 在 v6 使用同一 Model.predict 路径验收、选择与逐条预测。重新运行公开 C 三轮，重载后预测 23,049 条，逐项核对结果。
4. 用逐轮增长的公开训练子集做预算压力测试。三题十轮均完成，SDK 记录最终请求分别为 28、25、13 个 epoch。
