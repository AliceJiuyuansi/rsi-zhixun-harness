# 智训引擎企业赛系统运行说明 · 源码 0.19

## 提交内容

- Harness 镜像 `zhixun-rsi-harness:0.19`，目标 `linux/amd64`，使用官方 Contest Harness SDK 1.0.5。
- 驱动模型 `Qwen/Qwen3.5-4B`，由赛事宿主提供网关。本次使用基础模型，未进行大模型微调。
- 本地基线为 `0.18`，平台对照为第 15 版 `0.17` 企业赛试运行，运行 ID `e2f7c3cac9ce79a072af91a47e0fca92`。
- 完整提交的源码提交和 SwanLab 实验链接见平台作品字段。镜像 OCI revision 记录与源码同一提交，镜像构建时校验运行文件摘要和 SDK 导入。

## 运行接口

```bash
docker load -i zhixun-rsi-harness-0.19.tar
docker run --rm --network none zhixun-rsi-harness:0.19 describe
```

宿主在每轮提供 `/data`、父检查点及上一轮状态，调用 `python3 /app/harness.py train`。SDK 通过标准输入输出通信，候选和状态写入 `/workspace`。Harness 先做漂移诊断并计算规则预算，向宿主请求一次模型回执，再执行有上限的续训。候选与父模型在同一验证集比较。候选未晋升或续训失败时沿用父检查点。预测入口 `python3 /app/harness.py predict` 处理单条 SDK JSON，输出 A 类标或 B/C 非负剩余寿命。模型推理只依赖样本特征和检查点，镜像在离线环境运行。

## 版本变化与实验边界

B 组延续 `sign_log_v1`。校准器预测低于基础 MLP 时，几何融合在对数空间使用校准权重 `0.90`。其余样本沿用 `0.80`。参数随检查点保存，缺少新字段的旧检查点按此前方式预测。训练拟合仅使用训练集，验证标签只用于评估和晋升决策。

九根公开训练轴承逐一留出时，每折从该折训练轴承重新训练基础模型。等权 RMSE 从 435.71 降至 420.21 分钟，短轴承组均值从 166.33 降至 142.75。独立公开验证的 `Bearing1_4` 为 243.62 至 240.10，`Bearing2_4` 为 198.10 至 187.14，`Bearing3_4` 为 645.57 至 646.53。该筛查对照为固定基础预测的校准消融。

SDK 1.0.5 本地替身宿主对 v18、v19 各跑 A、B、C 十轮。B 的公开验证总体 RMSE 为 577.29 至 576.92 分钟，三根验证轴承各自改善。工程单测通过 104 项。该回放使用官方公开数据和确定性模型回复，验证交付接口与模型行为。

A 组纠错头在跨批次公开数据中仅挽回 3/109 条乙醛。C 组工况偏移在公开整机留出数据中汇总 NASA 罚分仅下降约 0.10%。两项消融未达验收线，0.19 沿用 0.18 的 A 策略及 C 校准搜索提速方案。隐藏数据收益以赛事平台报告为准。
