# 智训引擎企业赛 · 进阶指导与创新方案

**作者**：GeminiNeon (Web)  
**基准锚点**：平台第 18 版正式评测（代码 `0.17`，客观分 **28.3358 / 35**，剩余 **7 次试运行 + 1 次正式评测**）  
**适用目标**：在不动用最后 1 次正式评测的前提下，以最高性价比突破客观分瓶颈（冲刺 **31.5~33 / 35**），同时补齐两项审核标志并打造面向 **65 分专家主观分 + 10 分加分** 的差异化双层自进化证据链。

## 一、跳出原指南的四个核心判断

在复盘第 18 版正式回执后，有四个容易被忽略、但直接决定后续涨分上限的结构性判断：

1. **资源效率已满分溢出（5.0000 / 5），存在“合法的计算盈余”**
   - 第 18 版平台计量训练 `1,581.75s`、大模型 `13,897 tokens` 已直接拿满 **5.0000 / 5**。
   - 后续**彻底停止**减 epoch 等有损降耗实验，把 `~1,600s` 和当前 token 规模作为**回归红线**；在红线内，可以把算力盈余精准投向**轻量级无监督域对齐**和**关键域切换轮次的双候选验证**，用零扣分的计算换客观分。
2. **保持性近乎满分（4.9428 / 5），当前系统其实是“过稳、塑形不足”**
   - 客观分剩余 **6.6642 分** 失分高度集中于：平均阶段增益（丢 3.51 分）、最差阶段（丢 2.07 分）、漂移恢复（丢 1.03 分）；而保持性仅丢 **0.0572 分**。
   - 这说明现有晋升与更新策略偏保守（Stability-Plasticity 失衡）。因此对原指南中“增加旧阶段硬门禁防遗忘”的提议应**高度警惕甚至降级**——在保持性已达 4.94/5 时继续收紧拒绝门槛，极易误杀新域恢复、拖累最差阶段。
3. **A 组不是单一尺度漂移，而是“乘性衰减 + 加性基线偏移 + 难类对边界坍塌”**
   - A 组阶段增益呈明显双坑（第 1 阶段 `0.0775`、第 3 阶段 `0.1131`），且 `A-domain-transition-02 / 07` 未恢复，公开留出批次中 109 条乙醛有 108 条错判为乙醇。
   - 仅靠粗粒度的样本内归一化，容易把不同物理量纲的传感器通道混在一起，且无法解决新批次刚到达、尚无足够新标签时的首轮断崖下跌。
4. **75 分主观+加分才是拉爆对手的主战场，但先决条件是排雷两项 `false`**
   - 第 18 版中 `材料与可复现性=false`、`实验记录完整性=false`。在客观分已站稳 28.34 的前提下，**排雷审核门禁 + 拿出真正有因果证据的策略层自进化（PyTRIO LoRA）**，单位投入的总分回报远高于继续在离线死磕 0.5% 的微小指标波动。

## 二、针对现有做法的 4 个精准补丁

以下补丁改动小、风险低，建议作为后续所有实验的前置底座：

### 补丁 1：审核门禁“一跑一档”自动化闭环（最高优先级）
- **问题诊断**：第 18 版复用第 15 版镜像并采用事后补录的 SwanLab 链接，很可能触发了“实验记录与正式提交时间线/运行身份未强绑定”或“说明附件缺关键字段”的判定。
- **补丁做法**：
  1. 先查明两项 `false` 的具体缺失口径（是人工未复核，还是缺原生实时记录/固定字段）。
  2. 建立提交前自动校验脚本：每次试运行与正式评测自动绑定 `git SHA`、`镜像 digest`、`提交 ID`、`系统说明 ID`、`模型/权重 ID`、`SwanLab 实时 Run URL` 与 `逐轮父子检查点血缘`，提交前强制跑一次**匿名无登录访问检查（HTTP 200 + 关键图表可读）**。

### 补丁 2：用“软正则 + 漂移感知放行”替代“旧阶段硬拒绝门禁”
- **问题诊断**：在保持性已达 `4.9428 / 5` 的状态下，硬加旧阶段拒绝阈值大概率降低恢复率。
- **补丁做法**：
  - 保留少量旧阶段样本仅做**监控指标与轻量防遗忘软正则**（如对旧权重加极小系数 L2-SP 或 EMA 混合），**不作为硬一票否决条件**。
  - 当检测到显著域切换（无监督特征均值/方差偏移超阈值）时，允许适当放宽单轮更新塑形能力，优先保证 `transition` 成功恢复。

### 补丁 3：A 组特征改造升级为“物理分组归一化 + 残差拼接”
- **问题诊断**：气体传感器阵列（MOX）特征通常包含稳态响应、归一化响应、上升/下降动态斜率等不同物理量纲。若对整条特征向量直接做统一归一化，会破坏不同物理通道的量纲语义。
- **补丁做法**：
  - 按物理特征类型分组（同一物理量纲跨 16 个传感器通道内部做 L2/Z-score 归一化与通道间 Log-Ratio），再与原始特征**残差拼接（Concat）**，接一层带 `LayerNorm` 的轻量线性映射。
  - 既保留绝对浓度幅度，又精准消除跨批次乘性灵敏度漂移。

### 补丁 4：PyTRIO 账本核销与 Prompt Cache 瘦身
- **账本补丁**：将 SQLite 账本从“按最大上下文永久预留 ¥3/笔不核销”改为三态流转：**发送前按估算预留 → 收到 usage 立即按实核销 → 仅超时/异常单列挂账**，彻底解除假预算锁死。
- **Prompt 补丁**：将静态系统提示词与动作定义固定置于 Prompt 头部，吃满 **Prompt Cache**（显著降低输入成本）；每轮动态输入压缩为紧凑 JSON 诊断向量（漂移统计量、预测熵、高混淆类对置信度边界占比、父模型近 2 轮趋势、剩余预算），兼顾低 token 与高信息密度。

## 三、四大可落地的创新策略

### 创新 1：A 组“无监督测试时域对齐（AdaBN-Lite）+ 余弦分类头 + 难类对边界校准”
**瞄准目标**：A 组约 **4.42 分** 客观分空间（首阶段 `0.0775`、第 3 阶段 `0.1131` 及 `transition-02 / 07` 未恢复）。

1. **合规无监督域对齐（解决新批次刚到达时的首轮暴跌）**
   - **原理**：新阶段数据到达但尚未完成有效续训前，传感器基线与增益已发生偏移。仅使用**当前轮次平台允许到达的无标签/已到达批次特征**，计算批次特征均值与标准差，与父模型记录的参考域统计量做**动量滑动对齐（Momentum AdaBN / Feature Whitening Lite）**。
   - **优势**：无需新标签即可在域切换首轮直接拉平分布偏移，且 CPU 开销可忽略不计。
2. **余弦相似度分类头（Cosine Classifier Head）**
   - 将末层线性分类头替换为特征与权重均做 L2 归一化的余弦分类头（带可学习温度系数 $\tau$）。
   - **物理契合度**：气体传感器老化最常见的就是特征向量整体模长衰减，余弦分类头天然对模长缩放免疫，只依赖通道间的方向夹角（气体指纹）。
3. **乙醛/乙醇难类对边界专项校准**
   - 针对历史混淆矩阵中最高误判类对（乙醛 vs 乙醇），在续训动作中增加可选的 **难类对重加权（Focal / Class-Balanced Logit Adjustment）**，专门拉大两者的决策边界，同时严格监控六类 Macro-F1 与最低类召回。

### 创新 2：C 组“NASA 非对称感知恢复 + 关键切换轮次轻量双候选竞赛”
**瞄准目标**：定向攻克 `C-domain-transition-02` 未恢复，守住 B/C 既有高分。

1. **NASA 非对称偏置保护动作**
   - NASA 罚分对**高估剩余寿命（预测 > 真实）**呈指数级惩罚，而常规 MSE 联合更新在域切换初期容易产生系统性高估。
   - 在 C 组动作空间中新增**“低学习率主干微调 + NASA 非对称偏置微调（Asymmetric Bias Shift）”**动作：微调主干后，在验证侧用极小步长搜索单标量安全偏置，压制极端高估罚分。
2. **域切换双候选竞赛（用资源盈余换确定性）**
   - 仅在检测到 C 组域切换的少数关键轮次，并行生成两个候选：`[纯校准]` vs `[低 lr 联合更新 + 非对称偏置保护]`，在同父验证集上按 **RMSE 与 `log(1+NASA)` 联合帕累托更优** 决定晋升；非切换轮次保持原有低耗策略。

### 创新 3：策略层升级为“反事实物理反馈 → 27B 教师蒸馏过滤 → 4B LoRA 进化”闭环
**瞄准目标**：解决“之前大模型盲测不如固定规则”的根本矛盾，同时打造 **65 分主观分 + 10 分加分** 的王牌交付物。

此前 4B/27B 盲测未赢固定规则，核心原因不是大模型不行，而是**动作菜单太贫瘠（多数状态各动作差异极小）+ 缺少物理诊断特征**。建议按四步重构策略层：

1. **重构有区分度的物理动作菜单**
   - A 组：`[keep_parent, standard_ft, drift_align_plus_ft, hard_pair_reweight_ft]`
   - C 组：`[calibrate_only, low_lr_joint_ft, asymmetric_nasa_recover]`
   - B 组：冻结固定 `0.80` 融合（保持简洁稳健）。
2. **在服务器 CPU 上生成“反事实轨迹数据集（Counterfactual Dataset）”**
   - 对同一父检查点，把上述动作**全部真实跑一遍**，记录每个状态下每个动作的真实反事实收益（`ΔMacro-F1`、`ΔWorst-Recall`、`ΔNASA`、`ΔRetention`、`CPU`）。
   - 过滤掉所有动作差异微弱的“噪声状态”，只保留**选对动作确实带来显著净收益的高价值关键状态**。
3. **27B 离线教师蒸馏 + 反事实真值过滤（Rejection Sampling）**
   - 让 **27B** 在高价值关键状态上生成简短、结构化的“漂移诊断 → 动作选择”推理链（Best-of-N）。
   - **用真实 CPU 反事实执行结果当裁判**：只保留“诊断逻辑自洽且最终选中真实最优动作”的样本；剔除所有选错的幻觉样本。
4. **4B LoRA 监督微调（可选加 1 轮轻量偏好精调）**
   - 用这份经过物理执行验证的高纯度反事实数据集，对 **`Qwen/Qwen3.5-4B`** 做 LoRA 微调，冻结产出可加载的 `trio://` 权重。
   - **部署优势**：线上只跑轻量 4B LoRA，推理极快、Token 极省、资源效率稳守 **5/5**，却继承了 27B 的诊断能力与真实工业执行反馈！这正是评委最看重的 **“模型层 + 策略层双层自进化（RSI）”** 硬核闭环。

### 创新 4：三层可解释安全架构（大模型提议 + 规则硬护栏 + 验证同父裁决）
- **结构**：`4B LoRA 策略器（输出结构化诊断与动作）` → `硬护栏（预算/格式/合法性校验，异常时无缝回退安全默认动作）` → `验证集同父晋升裁决`。
- **证据自动化**：每轮自动生成标准化 `decision_card.json`（含输入漂移特征、模型诊断摘要、所选动作、父子验证对比、晋升结论、耗时与 Token），实时同步到 SwanLab。评委任意抽查一轮均可实现 **假设 → 代码 → 检查点 → 证据 → 指标** 秒级溯源。

| 轮次 | 变更内容（以 `0.17` 为基线） | 核心验证目标 | 过线标准 |
|---|---|---|---|
| **试运行 #1** | 仅合入 **A 组工业革新**（物理分组相对特征 + AdaBN-Lite 域对齐 + 余弦分类头/难类对校准） | 验证跨物理批次隐藏 Macro-F1 是否实质突破 `0.874`；检查早期弱阶段与 `transition-02/07` 恢复 | A 隐藏 Macro-F1 显著提升（目标 `≥0.895~0.91`），B/C 不变，总训练秒数接近红线不暴涨 |

## 六、执行优先级总览（给实施者的行动顺序）
