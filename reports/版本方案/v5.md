# v5 · 按运行工况拟合 C 残差

平台试运行 `48a05570ca992a4144cf98b004e9352e`，版本 `5a45bc60cf3f4ea34b35a3fa1f99bd4d`。A/B/C 各完成十轮。

## 方案与改进依据

无上限父模型在不同发动机工况下仍有系统偏差。检验训练集拟合的残差能否迁移到平台隐藏集。

只在 C 上启用校准。以训练集工况均值和标准差归一化 21 个传感器，拟合带岭惩罚的分段线性残差。已见工况的修正最多 ±10 个循环，未见工况使用父预测；每个 epoch 重新拟合，随检查点保存。
