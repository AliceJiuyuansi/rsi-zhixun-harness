# C 组 NASA 尾部优化：0.9.1 与 0.9.2 双版本方案与本地验收

基于 `v9`（`3209579`）在本地真实公开包 `baselines/C-engine`（训练 113,089 行、验证 23,049 行，训练/验证发动机无交集）完成解耦因子消融与代码升级。**A/B 任务零改动，检查点 SHA 逐位一致**；原有 `v8`/`0.9` 校准逻辑与旧检查点 100% 向后兼容。

## 1. 根因定位与因子消融结论

1. **为什么 v9 的 C 组 NASA 卡在 ~2.8×10⁹ 降不下来？**
   - 公开验证集 NASA 惩罚中 **96.7%~98.4% 来自极端低估尾部**（如 `FD004-u179` 低估 -250 循环单机占 57.8%，`FD004-u201` 低估 -249 循环占 28.7%），而 `FD003-u73` 存在 +170 循环高估。
   - v8/v9 原版 [c_calibration.py](file:///D:/北京创新赛/rsi-zhixun-harness/vendor/contest_baselines/c_calibration.py) 将总修正量硬限幅在 **`±10.0`**、工况风险平移仅搜索 **`[-3.5, +0.5]`**，面对上百循环的尾部残差几乎锁死。
   - 原版样条未引入 `parent_prediction` 及其分工况交互，6 种工况共用一套样条系数，表达能力受限。
2. **解耦因子消融结论（防止多因子互相干扰）**：
   - **否定因子（不合入）— 修改 `model.py` C 任务训练损失**：在保持校准不变的前提下，将 `model.py`（batch_size=128、全工况混合标准化）的 MSE 替换为 Entropic-NASA 复合梯度后，VAL RMSE 反而从 `51.42` 恶化至 `51.86~53.80`，NASA 波动至 `4.59e9~9.11e9`。因此**完全保留 `model.py` 纯 MSE 续训不动**。
   - **有效因子 — 升级 `c_calibration.py` + 非对称限幅抑制高估反弹**：直接放宽对称限幅（如 `±120`）会大幅压低 FD004 低估尾部，但会把 `FD003-u73` 推向更高估（因高估惩罚 `exp(+d/10)` 比低估 `exp(-d/13)` 陡 1.3 倍）。采用**非对称限幅（宽松负向、保守正向）+ 训练集分工况风险平移**后，可同时压低总 RMSE 与 NASA 且稳住 FD003。

## 3. 镜像构建与一键切换方式

```bash
# 版本 A（保守极速解析版 0.9.1）
docker build --platform linux/amd64 --build-arg RSI_RELEASE=0.9.1 -f harness.Dockerfile -t zhixun-rsi-harness:0.9.1 .

# 版本 B（极致降分残差 MLP 版 0.9.2，默认）
docker build --platform linux/amd64 --build-arg RSI_RELEASE=0.9.2 -f harness.Dockerfile -t zhixun-rsi-harness:0.9.2 .

# 原版 v9 对照（0.9）
docker build --platform linux/amd64 --build-arg RSI_RELEASE=0.9 -f harness.Dockerfile -t zhixun-rsi-harness:0.9 .
```
也可在运行时用 `RSI_C_CAL_MODE=spline_v2|res_mlp_v1|v8` 显式覆盖。
