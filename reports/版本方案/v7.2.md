# v7.2 候选版本与公开验证

2026-11-24。本版以 v5 为对照，只将 v6 的训练策略用于 A。三种数据到达顺序各跑十轮后，A 在两种顺序中提高，平均 macro-F1 下降 0.001910。B、C 的晋升轮次和最终逐条预测全部与 v5 一致。**首次正式评测继续选 v5；v7.2 归档为工程候选。**

## 更新了什么

- **A 沿用 v6。** 首轮请求 5 个 epoch，随后有新增训练数据时请求 3 个，否则请求 1 个，累计最多请求 28 个。闸门仍可缩减预算。候选与父模型在同一批验证样本上比较，macro-F1 下降不超过 0.02 也允许晋升。
- **B、C 恢复 v5 的预算和预测行为。** 去掉 v6 额外设置的累计 25、13 个 epoch 限制，保留 v5 的逐轮预算、最多 10 次更新和停训规则。C 切阶段时恢复按数据漂移分配预算。B、C 预测均保持非负，取消 1200 分钟和 260 循环的硬上限。C 沿用 v5 工况校准，每条校准量限于 ±10 个循环。
- **修复源码与镜像入口的不一致。** Docker 和本地入口默认版本统一为 0.7.2。纳入主分支 16f1620 已补齐的无上限预测与轴承分组读取，分组用于报告误差。保留 v7.1 的 C NASA 尾部指标、模型调用回执、实际训练轮数与所选检查点轮数记录。
- **修复故障验收。** 从团队工作区恢复被忽略的六个 `src/data` 源文件，逐一与 v5 镜像内的文件比对，忽略换行格式后内容相同。Git 的数据忽略规则收窄到根目录 `/data/`。

### 发布开关

| v7.2 运行条件 | B/C 预测绝对上限 | C 新拟合 |
|---|---|---|
| 默认镜像（0.7.2），或本地两个环境变量均未设置 | 无 | 开启，修正最多 ±10 |
| 显式设置 `RSI_C_CALIBRATION=0` | 无 | 关闭；继续使用父检查点已保存的校准 |
| 显式设置 `RSI_C_CALIBRATION=1` | 无 | 开启 |

在本版代码中，单改 `RSI_RELEASE` 不会恢复预测截断。未显式指定校准开关时，本地入口对 0.7、0.7.1、0.7.2 默认开启新拟合；历史版本用该版本的镜像复现。

## 与 v5 的本地十轮对照

两版共 180 轮。使用官方 SDK 1.0.4、本地模拟宿主和官方公开数据，模型回执固定为空，两版都走规则决策。每个顺序从同一初始权重开始，训练数据从 40% 增至 100%，每三轮换阶段，验证集固定。顺序 7 和 42 指分别用这两个随机种子打乱训练行，然后逐轮提供前缀。数值取第十轮最终选中的模型。[协议配置](../../configs/exp/v7_2_public_pair.yaml) · [全部数值、晋升轮次和预测哈希](../试运行证据/v7.2_公开十轮配对.json)

|---|---:|---:|---:|---:|---:|
| 原始 | 0.735318 | 0.722549 | −0.012770 | 649.635 | 50.218 |
