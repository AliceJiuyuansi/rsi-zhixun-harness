# v8 · 有预算约束的更新与选模

基线：`16f1620`（v7.1）。本版是 Git 源码候选，不是赛事平台已测版本；正式推荐仍沿用已测 v5。没有证据说明 v8 的隐藏成绩或单位算力收益高于基线。

| 模块 | 决策与约束 |
|---|---|
| 模型回执 | 请求首行 JSON、`/no_think`，请求上限 768 token，服从宿主给出的正限额。实时路径只在 `finish_reason=length` 时尝试恢复明确但被截断的 JSON 动作；不能确定则执行规则。调用失败不写异常消息。`changed_rule` 指裁决在下游安全闸之前是否改变了规则提案，不等于最终执行。 |
| C 残差校准 | 在训练集上对父模型高估样本赋权 1.35 做岭回归。每个至少 64 行的工况在 `[-3.5, 0.5]` 的 17 点上最小化 `RMSE/RMSE₀ + 0.05 × NASA/max(NASA₀,1)`；最优点须满足 RMSE 恶化不超过 0.15%、NASA 下降超过 2%，否则偏移为零。训练搜索与服务使用同一限幅（总修正 ±10）和非负输出。未知工况返回非负父预测。 |
| 候选晋升 | A 保持原有容差。B 至少两个可比较轴承时，用总体增益与逐轴承相对增益的 70/30 混合辅助判断；总体 RMSE 恶化超过 0.05% 不予挽救。C 的 `nasa_log1p` 增加超过 0.50 一律拒绝；RMSE 增益至少 0.05% 且 `nasa_log1p` 下降至少 0.15 时可晋升。缺少配对辅助指标时沿用主指标。 |
| 权重平滑 | 测试 `0.85 × 最佳 epoch 权重 + 0.15 × 父权重`；C 重新用训练集拟合校准。在同一验证集，主分数高出原快照超过 `1e-12` 才采用，数值失败保留原快照，不多记一次训练 epoch。 |

**实现口径。** 原方案的公式与示例常数不同；本版按数学定义采用 1.35、17 点、0.05 和明确的 NASA/RMSE 门槛，C 尾部否决不附加“RMSE 增益小于 1%”例外。工况偏移是有限网格上的训练经验最优，不是总体贝叶斯最优；权重择优保证的是同一验证集上的主指标，并不保证后续阶段不退化。

**复核。** 环境需要 Python 和 NumPy。运行 `python3 -m unittest discover -s tests -v`。准备官方 SDK 1.0.4 后可用 `docker build --platform linux/amd64 -f harness.Dockerfile -t zhixun-rsi-harness:0.8 .` 构建镜像。下一步在公开阶段固定数据顺序与起始检查点，逐一开关上述模块，比较晋升轮次、各任务指标、CPU 时间及 token 用量；仅凭离线单测不能证明线上截断已消除。
