## B 的退化发生在哪里

B 公开训练集 7,032 条，真值 p99 为 2,481 分钟、最大 2,537；公开验证集 1,679 条，p99 为 1,497.22、最大 1,514。1,200 确实会压低长寿命预测。真值超过上界的记录数与模型预测实际触及上界的记录数是两个量。

| 平台 B | v5 无上界 | v6 上界 1,200 |
|---|---:|---:|
| 第 8 轮候选相对父模型的验证增益 | +0.3297%，晋升 | −0.0991%，保留父模型 |
| 第 9 轮 | 请求 3 epoch，晋升 | 请求 0 epoch |
| 最终使用的检查点 | 第 9 轮 | 第 2 轮 |
| 最终公开阶段 RMSE | 652.942 | 654.116 |
| 最终隐藏 RMSE，200 条预测 | 352.083 | 569.046 |

平台回执确认了第 8 轮选模分叉。固定公开末轮检查点把截断关掉，RMSE 从 649.239 变为 649.635；仅这个开关的直接效应无法解释隐藏 RMSE 增加 216.963 分钟。两版最终使用了不同的权重，隐藏样本触发截断的具体条数及两个机制各自的贡献无法从聚合回执还原。

## 复现与接手

在仓库根目录放好官方 SDK 1.0.4 与公开任务包。PowerShell 中设置 `$env:RSI_RELEASE='0.7'` 即启用 v7，未设置时保留既有默认行为。以下本地命令会使用真实检查点和 SDK 的本地宿主。输出目录会由测试脚本创建。

~~~powershell
$env:RSI_RELEASE='0.7'
python scripts/test_harness_local.py --dataset B --rounds 3 --stage-every 10 --stub empty --save-selected out/v7-early-B.npz
python scripts/test_harness_local.py --dataset B --rounds 10 --grow --stage-every 3 --stub empty --save-selected out/v7-B.npz
python scripts/compare_prediction_caps.py B data/raw/official_b out/v7-B.npz out/v7-B-sweep.json
python scripts/test_harness_local.py --dataset A --rounds 10 --grow --stage-every 3 --stub empty --save-selected out/v7-A.npz
python scripts/test_harness_local.py --dataset C --rounds 3 --stage-every 10 --stub empty --save-selected out/v7-C.npz
~~~

v7 本地镜像可用 `docker build --platform linux/amd64 -f harness.Dockerfile --build-arg RSI_RELEASE=0.7 -t zhixun-rsi-harness:0.7 .` 构建。已完成三题 SDK 验证和 32 项单元测试。公开 C 四档实验在同一检查点和 106 台发动机上对照：基线 NASA 的 97.3% 来自 FD004；在 ±10 校准上再加 260 上界，NASA 额外降低 1.26%，MAE 和 RMSE 均略升。
