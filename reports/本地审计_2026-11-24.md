## 2. C 公开验证对照（23,049 条，同阶段第 3 轮模型）

| 方案 | MAE | RMSE | NASA（越低越好） |
|---|---:|---:|---:|
| v3：第 3 轮 + 145 上限 | 40.537 | 58.158 | 7.346×10¹⁰ |
| v4：同权重，撤销上限 | 37.856 | 51.691 | 4.321×10⁹ |
| **v5：工况校准，最多 ±10** | **36.536** | **50.049** | **2.378×10⁹** |
| 参考：全量修正（不选） | 34.091 | 48.119 | 4.571×10¹⁰ |
| 参考：±20（不选） | 36.043 | 49.433 | 1.789×10⁹ |

**相对 v4 无上限**：MAE -3.49%、RMSE -3.18%、NASA -44.97%。

### 校准怎么做

1. 只用**公开训练集**；按第一项运行设置的舍入值分工况；
2. 在每组内估计 21 个传感器的均值/方差，做工况归一化；
3. 用 5 个分位节点的分段线性函数，拟合父模型在训练集上的残差；
4. 每个样本最多修正 ±10 个循环；未见过的工况沿用父预测；
5. 校准参数随检查点保存，服务端 `Model.predict` 直接使用，只依赖 NumPy。

### 已验证 / 未验证

- 已验证：113,089 训练行、23,049 验证行、3 轮本地 SDK、检查点保存/重载、
  逐条 `predict()` 走正式提交模块；集成后的逐条结果与离线批量结果一致。
- 已验证：四个 FD 子集的 RMSE 均下降；NASA 在 FD001/FD004 下降，FD002/FD003 略升。
- 未验证：隐藏集。公开验证集同时用于早停和候选比较，属于候选筛选，不能承诺隐藏收益。
- 未验证：更大修正幅度（±20）虽然公开数字更好，但没有独立新阶段证据，暂不选。

## 3. 三项工程修复

| 问题 | 实测 | 修复 | 验证 |
|---|---|---|---|
| 特征路径重复 JSON 编码 | 六个公开文件单遍读取 CPU 23.13 s | `lru_cache(2048)` + tuple path | 23.13→7.56 s（-67.3%）；本机复测 23.54→7.94（-66.3%） |
| 历史增益写反 | v3 C 第 1 轮实际 +0.9805%，提示写成 -10.701% | 用每轮 `configuration.gain`，不做跨阶段差分 | v2/v3 共 60 条记录核对一致 |
| 连续训练失败不熔断 | 独立 9/9 通过，但训练入口第 4 轮仍尝试 | 恢复 `kill_state`，成功/失败更新计数 | 3 次失败后第 4/5 轮零预算，正常结束 |

- 读取缓存的 ID 顺序、特征路径、特征数组、标签数组逐项一致；非法输入行为不变。
- 历史修复不改变正常轮次的预算，只修正模型提示和 `finish.reason` 里的历史。
- 熔断修复不改变健康路径；只在连续异常时提前停止。
