## 2. v2 相对 v1 的变化

### 2.1 指标

| 数据集 | 指标 | v1 | v2 | 变化 |
|---|---|---:|---:|---:|
| A 气体 | macro-F1 | 0.8735 | 0.8674 | **-0.0060（-0.69%）** |
| A 气体 | accuracy | 0.8795 | 0.8729 | -0.0065（-0.74%） |
| B 轴承 | MAE（分钟） | 506.67 | **251.70** | **-254.98（-50.3%）** |
| B 轴承 | RMSE | 708.58 | **352.08** | **-356.49（-50.3%）** |
| C 发动机 | MAE（循环） | 41.12 | 41.12 | 0（同一模型） |
| C 发动机 | RMSE | 56.38 | 56.38 | 0 |
| C 发动机 | NASA | 8.85×10¹⁰ | 8.85×10¹⁰ | 0 |

**解读**

- **B 是这次最大的收益**：MAE/RMSE 直接减半。v1 在 B 第 2 轮后就停（后续候选被拒但还在训）；
  v2 在第 2 轮用 3 epoch 校准、第 3 轮再试、第 8/9 轮又拿到正收益，最终选中第 9 轮模型。
- **A 小幅回落**：-0.0060 F1。v2 在 A 的总 epoch 从 28 降到 23，部分新阶段只给 2 epoch；
  下一次可以把 A 的新阶段预算调回 3，或对 A 放宽“停手”。
- **C 完全没变**：v2 选中了和 v1 相同的第 3 轮模型，后面的训练都被拒；停手规则只是省了算力，
  没有改变最终产物。C 的 NASA 必须靠 v3 的 145 上限，而不是靠“少训”。

- prompt tokens 上升，是因为 v2 每轮把历史 + 漂移状态放进模型提示；completion 没变（仍是 10×768）。
  这笔 token 换来了可审计的决策理由，但模型文本仍为空（见 2.3）。

### 2.3 决策与停手

| 数据集 | v1 规则 | v2 规则 |
|---|---|---|
| A | 10 轮都有动作 | 首轮 5ep；新阶段 2–3ep；校准 1ep；共 23ep |
| B | 每轮 5ep，共 50ep | 首轮 5；校准 3/3；quiet 0；新阶段 4；stalled 0/0；新阶段 4；校准 3/3；共 25ep |
| C | 每轮 4ep，共 41ep | 首轮 3；校准 3/3；新阶段 3；quiet 0/0；新阶段 3；stalled 0；新阶段 3；stalled 0；共 18ep |

- 停手规则确实生效：B 第 4/6/7 轮、C 第 5/6/8/10 轮 `epochs=0`（共 7/30 轮；B 第 10 轮是 3 epoch 校准但被拒，不是 0）；
- **模型裁决仍然全是 `unavailable`**：10 轮 `content`/`reasoning_content` 都没取到文本，
  reason 如实写“无文本，按规则执行”。没有伪造模型判断；但“自主决策/记录分析”的素材仍不足，
  这是下一版要解决的展示问题。

### 2.4 v3 的 C 上限：实测证伪

v3 只改了 C 的预测上限（`min(value, 145)`），A/B 与 v2 **逐位相同**，所以 C 的变化可以归因：

| C 指标 | v2（无上限） | v3（上限 145） | 变化 |
|---|---:|---:|---:|
| MAE（循环） | 41.12 | **43.79** | +2.67（+6.5%） |
| RMSE | 56.38 | **62.88** | +6.50（+11.5%） |
| NASA | 8.85×10¹⁰ | **2.44×10¹²** | **27.6×** |

原因：C 的 RUL 真值并不止 145。公开训练集最大 **542**、99.5 分位 **419**；
公开验证集有 **7,599 / 23,049（33%）** 的样本真值 >145。上限把 33% 的预测压成低估，
而 NASA 对低估是 `exp(-d/13)-1`，误差同样指数放大。

**结论：v4 应移除 145 上限**，回到 v2 的 C 预测行为；如果还要限制尾部，
只能用训练集高分位（如 99.5% = 419）这种不会切断真实 RUL 的界，而不是 145。

## 3. v1 / v2 / v3 的逐轮要点

### A

- v1：0.7140 → 0.9697（10 轮都 promote）
- v2：0.7140 → 0.9627（第 2/6 轮 retain，其余 promote）
- v2 的新阶段 PSI 比 v1 更干净：第 3 轮 0.573、第 7 轮 0.382，其他阶段 0.005–0.158；
  说明跨轮参考画像在起作用的，不是“每轮都报一个大 PSI”。

### B

- v1：第 1–2 轮 5+5 epoch，之后 8 轮每轮 5 epoch 但候选全拒；最终选中第 2 轮。
- v2：第 1 轮 5、第 2 轮 3（promote）、第 3 轮 3（reject）、第 4 轮 0、第 5 轮 4（reject）、
  第 6–7 轮 0、第 8 轮 4（promote）、第 9 轮 3（promote）、第 10 轮 3（reject）；
  最终选中第 9 轮，隐藏 MAE 251.70。
- 结论：**B 不是“多训就好”，而是“在对的阶段训对步数”**；v2 的校准/停手组合碰巧找到了更好的点。

### C

- v1：第 1–3 轮 5/4/4 epoch 全 promote，第 4–10 轮 4 epoch 全拒；最终第 3 轮。
- v2：第 1–3 轮 3/3/3 epoch 全 promote，第 4 轮 3（reject）、第 5–6 轮 0、
  第 7 轮 3（reject）、第 8 轮 0、第 9 轮 3（reject）、第 10 轮 0；最终仍是第 3 轮。
- 结论：停手省了 23 个 epoch，但**没有改变 C 的最终产物**；C 的问题在预测上限，不在训练预算。
