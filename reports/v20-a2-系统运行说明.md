# 企业赛 0.20+A2 候选系统运行说明

此候选供企业赛单次试运行使用。镜像标签为 `zhixun-rsi-harness:0.20-a2-trial`，目标平台为 `linux/amd64`。运行记录及状态中的 `release` 保留 `0.20`，以沿用原有策略开关。镜像的 `org.opencontainers.image.revision` 标签标识具体候选源码提交。

## 运行接口

平台使用 `python3 /app/harness.py describe|train|predict`。镜像默认执行 `describe`。SDK 为 1.0.5，协议为 `contest.harness.workspace.v2`。`train` 通过标准输入输出接收宿主的开始帧，读取 `/data` 中的公开训练及验证投影、`/previous` 的父检查点、`/state` 的跨轮状态，在 `/workspace` 写入候选及下一轮状态。宿主提供模型 RPC 并接收选中产物和状态。`predict` 逐行接受 JSON 样本，用宿主指定的检查点输出预测。宿主应授予 UID/GID 65534 对输入的读取权限和对 `/workspace` 的写入权限。镜像运行不需要网络或内置访问密钥。

## 每轮决策与续训

控制器读取历史轮次、行数与阶段变化，计算特征漂移和预测分布变化。规则给出训练预算，宿主模型答复可在预算内收窄动作。空答复使用规则决策。续训从父模型的权重、优化器与尺度参数开始，同轮公开验证集用于评价父子模型。门控、累计预算及停机逻辑继续生效，候选未通过晋升时沿用父模型。

A 为六类气体分类。首轮使用 0.20 原预算。从第 2 轮起，在任务累计预算裁剪之后、Gatekeeper 审核之前，A2 将当轮申请的 epoch 数裁至最多 1。原预算为 0 时保持 0。任务累计上限为 28。B 为轴承剩余寿命回归，使用 0.20 的固定 0.80 融合与同轮 RMSE/MAE 晋升规则。C 为发动机寿命回归，沿用 0.20 的 `res_mlp_v2` 校准、后期预算和 RMSE/NASA 评价。B/C 的模型生成、选择和服务代码沿用 0.20。A2 沿用原检查点及状态格式。

## 离线证据及局限

公开批次 1 内按类划出 87 行作为晋升验证集，将余行按类内源序号正向或反向分五个递增阶段放出，每阶段两轮。两个策略从相同官方父模型分别推进十轮，使用 SDK 离线空答复，每个顺序各重复四次。父模型此前已使用过完整公开训练分片。冻结选择结果后用同一个批次 2 的 1,244 行评分。

两种顺序中，每一对策略的终点检查点字节相同，均有 108 个乙醛样本被误分为乙醇。两个顺序的最低类别召回均为零。计时来自原单核、单线程 SDK 离线复验；镜像验证另行核对逐轮预算、选模及检查点。这些结果覆盖一个外层公开批次。企业赛试运行、隐藏集指标、真实模型回执及线上资源消耗均须由平台运行产生。

## 构建、加载与核验

将官方 1.0.5 SDK 置于 `_sdk/contest-harness-sdk-1.0.5/` 后，在候选提交根目录执行以下命令。源码的运行时清单位于 `release_manifest.json`。提交下的 `harness.Dockerfile` 使用明确的 COPY 路径装入运行时。

```sh
docker build --platform linux/amd64 -f harness.Dockerfile --label "org.opencontainers.image.revision=$(git rev-parse HEAD)" -t zhixun-rsi-harness:0.20-a2-trial .
sha256sum -c image.sha256
docker load -i zhixun-rsi-harness-0.20-a2-trial.tar
docker run --rm --network none zhixun-rsi-harness:0.20-a2-trial describe
docker run --rm --network none --entrypoint python3 zhixun-rsi-harness:0.20-a2-trial /app/scripts/check_release.py --root /app --layout image --require-sdk
```

在交付目录中，`release-verification.json` 对应实际保存及重新加载的 tar。`replay/` 保存镜像每轮 SDK 回执、状态、检查点及末轮服务预测。B/C 对照为原 0.20 研究镜像，同一公开分片、父检查点、行序、空答复和单线程配置。A 以两种既定增长顺序与冻结的离线记录逐轮对照。镜像回放用于核对策略执行；线上计时留待平台报告。
